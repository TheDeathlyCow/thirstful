# Thirstful 0.1.0: A first pre-alpha for Minecraft 1.21.1

A first pre-alpha build for Thirstful. The only purpose of this unlisted build is to gather feedback on the first features of Thirstful, it is very much not meant for use in mod packs. This is likely the only version that will be released for 1.21.1; I plan to migrate to 26.1 as the codebase in 1.21.1 is not quite good enough to handle what I want to be able to do in Thirstful in a way that is easily compatible with other mods.
